# Picture Talk images

MindQuest has 3 Picture Talk missions in every grade. Until a picture is added, the mission shows an emoji placeholder with the file path, so it still works.

## How to add a picture

1. Save the image with the exact name shown below, inside this `images` folder.
2. Keep this `images` folder in the same folder as `MindQuest.html`. The page looks for `images/g4/picture-1.jpg` next to itself.
3. `.jpg` is expected, but `.png`, `.jpeg` and `.webp` with the same name also work.
4. Best size: landscape (4:3 or 16:9), about 1200 px wide and under 500 KB. Busy scenes with lots of people, objects and something happening work best, because the child earns points for every detail they mention.

Each entry lists what the scene should show (use it as the brief for an illustrator or image generator) and the details the scoring listens for. Try to make sure those details are visible.
