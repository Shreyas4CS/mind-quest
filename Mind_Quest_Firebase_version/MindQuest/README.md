# MindQuest v2 by CognoSpace

Weekly game-based well-being quests for Grades 4 to 9, with a child dashboard and a shared Teacher & Parent dashboard.

**Start here:** `SETUP.md` (demo accounts, running it, Firebase, AI).

## Pages
| File | What it is |
|---|---|
| `index.html` | Landing page (about MindQuest, Log in and Create account buttons) |
| `login.html` | Log in, and "New child account" sign-up |
| `child.html` | Child profile (age, class, likes, hobbies, fears) and child dashboard |
| `quest.html` | The weekly quest player (about 22 minutes, 24 activities) |
| `staff.html` | Teacher & Parent dashboard: all children, then per child: overview with suggestions, well-being, time & focus, marks, notes & plan |
| `report.html` | Short report with "i" info buttons, Download PDF, Download glossary & details, Print |
| `setup.html` | One-time Firebase account setup |

## Code (`js/`)
`config.js` settings · `store.js` logins and data (Firebase or demo) · `content.js` well-being areas and the 4 weekly quests (CBSE-style Holistic Well-being Report Card areas) · `quest.js` activity player and time tracking · `story.js` animated story videos · `checks.js` "Get ready" camera calibration and microphone check before each quest · `camera.js` face reader · `arcade.js` + `css/arcade.css` all 19 game missions from MindQuest v1 (generated by `tools/build-arcade.py` from the v1 sources; edit those and rebuild) · `heart.js` HW-605 sensor (live BPM, oxygen, HRV, stress meter, pulse wave; saved per week for the report) · `scoring.js` scores, flags, marks alignment · `insights.js` AI and built-in suggestions · `glossary.js` info texts and glossary PDF · `charts.js` · `pdf.js` · `seed.js` demo data.

`functions/` holds the Firebase Function that keeps the Google Gemini API key on the server. `arduino/` holds the heart-sensor sketch.

MindQuest is a screening and conversation tool, not a diagnostic test.

Designed & developed by CognoSpace · www.cognospace.in

## Weekly quest (about 26 minutes)
Each week mixes all 19 MindQuest v1 game types (counting, Sound Quest, patterns, Choose Your Path, Echo Pads, Feelings Detective, Odd One Out, Number Mission, Flash Memory, Sound Lab, Speed Tap, Brain Riddle, Quick Catch, Read & Think, Listen Closely, Picture Talk, Say It!, Finger Math, Fastest Finger) with new content every week, plus the CBSE Holistic Well-being questions (situations and ratings rotate so every one gets asked over the weeks), a story video, a chat with Coggy, calm breathing, mood checks and the private check-in.
The report follows the v1 layout: cover with the Champ Profile, at a glance, key numbers, key insights, thinking skills, Big Five, emotional intelligence, mood, listening & voice, camera feelings and gaze, heart & body signals, mission details.
Picture Talk pictures: put them in `images/g4/picture-1.jpg` to `images/g9/picture-3.jpg` (see `images/README.md`).
